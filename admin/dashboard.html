Save Changes to GitHub reads products.json from your repo (GET), merges the pending changes, and commits it back (PUT) so GitHub Pages rebuilds. Credentials are stored only in this browser's localStorage.

Token needs public_repo scope for public repos or repo for private ones. Like the admin password, this is a client-side convenience — anyone with access to this browser can read the token.
